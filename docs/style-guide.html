Style guide

One design system. Any style guide.

Wayfinder uses the design system from Neocloud Supply OS, itself a port of the Ethical Tech CoLab design system. Every colour, typeface, radius and glow is a CSS variable. A style guide states a few core tokens; the theme engine derives the rest and enforces WCAG contrast, so no style guide can ship an illegible page. The default is the CoLab theme, as in Neocloud.

01 · Style guides

Lab themes, a wallet, and neocloud costumes.

Each card is drawn in its own theme. Presets other than the CoLab ones approximate public colours and type for demo dressing only. Proprietary typefaces are swapped for open-licensed look-alikes, and no logos are used.
